КИНО ДЛЯ LAMPA

Ссылка для установки:
https://dyurkov.github.io/lampa-kino-plugin/kino.js

В Lampa: Настройки → Расширения (или Плагины) → Добавить плагин.
Введите ссылку, сохраните и полностью перезапустите приложение.
Откройте пункт «Кино · новинки».

Для первой проверки выберите «Смотреть сейчас» → Wing It! → Смотреть.
Выбран вариант 480p для совместимости со старыми телевизорами.

Возможности:
- Каталог фильмов и мультфильмов за последние 365 дней через TMDB.
- Шесть открытых короткометражек с официального сервера Blender.
- Открытие собственной прямой HTTP(S)-ссылки MP4/HLS.

Каталог новинок не предоставляет доступ ко всем полным коммерческим фильмам.
Для их просмотра нужен отдельный доступный вам источник.
Русская озвучка открытых фильмов не добавлена. Есть фильмы без диалогов.
Sprite Fright — хоррор-комедия PG-13; Singularity может не поддерживаться старыми ТВ.

Проверено: ES5-синтаксис, 12 проверок логики с имитацией Lampa,
доступность видеоссылок и тип video/mp4. Проверка на вашем ТВ ещё нужна.

Код не собирает аналитику. Введённая видеоссылка не сохраняется плагином;
плеер и приложение могут вести собственную историю воспроизведения.

Исходники Lampa: https://github.com/yumata/lampa-source
Лицензии и источники фильмов: film-sources.json

# UA-агрегатор для Lampa

Дата проверки: 8 сентября 2026 года. Установка: [ua.js](https://dyurkov.github.io/lampa-kino-plugin/ua.js).

Это наш общий вход в источники просмотра. Откройте карточку фильма или сериала → **Смотреть → «Дивитися · UA»** (в некоторых версиях кнопка видна отдельно). Выберите источник. Для первой загрузки Online Mod нужен интернет.

## Что объединено

- **HDRezka, Filmix, CDNVideoHub, Kodik** — через Online Mod. Наш файл выбирает соответствующий источник и передаёт ему карточку фильма.
- **Дополнительные источники Online Mod** — отдельный пункт показывает те, которые сам плагин разрешает на вашем устройстве.
- **Уже установленные видеоплагины Lampa** — автоматически добавляются в общий список, если предоставляют стандартный обработчик запуска. Это включает совместимые установки Lampac и украинские плагины.
- **Украинские переводы в начале списка** — при открытии меню переводов в запущенном через агрегатор плеере. Сохраняются исходные индексы и текущий выбор; звуковая дорожка автоматически не переключается.

Агрегатор не выдаёт подписки и не гарантирует наличие каждого фильма или украинской дорожки. Токены и вход в сервис настраиваются в исходном плагине. Логику извлечения потоков выполняют подключённые источники; этот файл объединяет их запуск.

## Подключаемая зависимость

Наш JS не содержит копию Online Mod. Он загружает файл из репозитория автора через jsDelivr:

`https://cdn.jsdelivr.net/gh/nb557/plugins@5cd0cb37d2ca0321acf3471ad5e2048567ecdfef/online_mod.js`

Версия закреплена по commit SHA. В браузерах с поддержкой SRI проверяется SHA-384:

`sha384-Ju5poKIRm/gJEFvqSb5DtL/5cEAuYoTbqvUCqTZ0ra+LGGFevn544HGBzSgpkpcB`

Существующая установленная копия Online Mod используется без повторной загрузки. Исходный плагин управляет своими сетевыми запросами и настройками; наш агрегатор не запрашивает пароли и не добавляет серверные команды RCH.

При тайм-ауте загрузки перезапустите Lampa. Если появляется запрос входа или сообщение об ограничении доступа, это ответ источника; агрегатор не обходит его. Для Rezka Premium [разработчики Lampac отдельно сообщают об ограничениях сторонних приложений](https://github.com/lampac-nextgen/lampac/blob/main/Modules/OnlinePaid/Rezka/README.md).
